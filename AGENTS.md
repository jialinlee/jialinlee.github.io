# AGENTS.md

Rules for any agent (human or AI) working on this personal site (jialinlee.github.io).

## Never publish

- Never invent or embellish work experience, metrics, dates, titles, or credentials. Every factual
  claim about education, employers, roles, dates, and results must trace back to `resume.pdf.pdf`
  (or explicit instructions from Jaelyn in conversation).
- Never post content that could embarrass a named employer, portfolio company, or client. Deal
  names, client names, and company specifics not already in the CV stay out.
- Never include personal contact details beyond what's already public/approved (current CV phone,
  email, LinkedIn, GitHub, phone number). Don't add home address, etc.
- Never commit secrets, API keys, or analytics tokens into the repo.
- Never add tracking/analytics scripts, third-party embeds, or external fonts/CDNs without asking
  first — keep the site minimal and self-contained.

## Always ask first

- Before running any `git push`, opening a PR, or otherwise publishing to GitHub / GitHub Pages.
- Before deleting or overwriting `resume.pdf.pdf`, `photo.jpg.jpg`, or any other source asset.
- Before adding new sections, claims, or experience not present in the current CV.
- Before changing the color palette, domain, or overall structure in a way that's a significant
  departure from what was last approved.
- Before adding a contact form, newsletter signup, or anything that collects visitor data.

## Style

- Tone: professional but approachable — CBS MBA candidate, not a corporate law firm. Confident,
  concise, no buzzword soup.
- Visual identity: Columbia Business School blue as the primary color, clean/minimal layout, tile-
  or card-based sections, generous whitespace.
- Navigation: flat and direct — a handful of top-level links, no dropdowns/mega-menus, everything
  reachable in one click/scroll.
- Content order should mirror the CV's own section order (Education → Experience → Additional)
  unless Jaelyn asks for a different structure.
- Keep the page a single self-contained `index.html` (inline CSS/JS) unless asked to split it up.
- Mobile-friendly: no horizontal scroll, readable at phone width.
